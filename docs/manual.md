# 検数ログ（CountLog）使い方マニュアル

## 1. 目的 ― 数えることではなく、エビデンスを残すこと

このアプリの目的は「数えること」ではありません。**エビデンス（証拠）を残すこと**です。

数量検査で本当に困るのは、数える作業そのものではありません。出荷した後になって「数が足りない」と言われたときです。そのとき言い争いを終わらせるのは、記憶や言い分ではなく記録です。

- 品物と出荷伝票が一緒に写った写真
- 人が目視で確認して確定した個数
- 検査した日時

この3点が1セットで残っていれば、それは証拠になります。検数ログは、その記録を確実に残し、サーバーへ自動で送るためのアプリです。

## 2. 撮影の決まりごと

記録を証拠として成立させるために、次の決まりごとを守ってください。

1. **出荷伝票・識別札を必ず品物と一緒に写す**
   数量検査の写真を撮るときは、出荷伝票や識別のための札を、必ず品物と同じ写真の中に写してください。札が写っていない写真は、後から見ても「何の・いつの出荷か」が分からず、証拠になりません。
2. **品物は広げて一層にし、重ねない**
   重なった物は人間にも正確に数えられません。広げて一層に並べ、重ならない状態で撮ってください。
3. **1枚の写真に1品種だけ**
   品種が混ざると、数える対象を取り違えます。品種ごとに分けて撮ってください。
4. **明るい場所で、真上から撮る**
   暗い場所や斜めからの撮影は、影やゆがみで誤判定のもとになります。
5. **機械の数値は下書き。必ず目視で確認してから確定する**
   アプリが出す個数は下書きです。マーカーを見て漏れや数え過ぎを直し、必ず人が確認してから確定してください。

## 3. 操作手順

### 撮影

1. 「撮影」タブを開きます。
2. 「カメラで撮る」または「写真を選ぶ」で、検査対象の写真を用意します（伝票・札も一緒に写すこと）。

### 対象を囲む

3. 写真が表示されたら、黄色い四角をドラッグして位置を合わせ、四隅ではなく右下の丸いハンドルをドラッグして大きさを変え、**数えたい品物を1つ、ぴったり囲みます**。
4. 「この対象で数える」を押します。
   - 囲む操作をせずに数えたい場合は「自動（明暗）で数える」を押します。明暗のかたまりを数える方式で、背景との明暗差がはっきりしている写真向きです。

### 確認・修正

5. 数えた結果が、番号付きの赤いマーカーで表示されます。
6. マーカーを確認します。
   - **漏れている物がある** → その場所をタップするとマーカーが追加されます。
   - **数え過ぎている** → そのマーカーをタップすると削除されます。
7. 「対象を指定して計数」の場合、感度スライダーで判定の厳しさを調整して「再計算」できます（小さいほど厳しく＝少なく、大きいほど緩く＝多く数えます）。
8. メモ欄に伝票番号などを入力します（後から探す手がかりになります）。

### 確定

9. 「確定して保存」を押します。記録が端末に保存され、サーバーへのアップロードが自動で始まります。
10. 保存の確認が出たら「OK」を押して、次の検査に進みます。

## 4. 自動アップロードと保存先

- 確定した記録は、WebDAV サーバーへ自動でアップロードされます。
- 保存先は `<設定したURL>/<日付>/<記録ID>/` で、中身は次の3ファイルです。
  - `image.jpg` … 元写真
  - `marked.jpg` … マーカーを描き込んだ写真（何を数えたかが分かる証拠写真）
  - `record.json` … 日時・下書きの個数・確定した個数・メモなどの記録
- アップロードの状態は「履歴」タブの各記録の右側アイコンで確認できます（チェック＝送信済み、時計＝未送信、△＝送信失敗）。
- 通信できない場所で確定しても、記録は端末に残ります。アプリを次に開いたときに自動で再送されるほか、「履歴」タブの「未送信を再送」ボタンでも送れます。

## 5. WebDAV 初期設定の手順

初回だけ、「設定」タブで接続先を入力してください。

1. 「設定」タブを開きます。
2. **URL** … アップロード先のアドレスを入力します（例：`https://suica10.duckdns.org/countlog`）。
3. **ユーザー名** …（例：`counter`）。
4. **パスワード** … 対応するパスワードを入力します。パスワードは端末の Keychain に保存され、アプリ内のファイルには残りません。
5. 「保存」を押します。
6. 「接続テスト」を押して「接続できました」と出れば完了です。

## 6. 精度についての注意

- アプリのカウントは**下書き**です。囲んだ対象の見え方、照明、品物の重なりによって、漏れたり数え過ぎたりします。
- 検証では、広げて一層に並べた写真では高い精度が出る一方、物がくっついたり重なったりした写真では1〜2割程度少なく数える傾向がありました。
- **最終確認は必ず人が行ってください。** 「機械が数えた」ではなく「人が確認して確定した」記録であることが、エビデンスとしての価値です。
- うまく数えられないときは、決まりごと（広げる・重ねない・明るく・真上から）を見直すのが一番の近道です。

## 7. 記録の見方

- 「履歴」タブに、確定した記録が新しい順に並びます。
- 各記録には、写真のサムネイル、日時、確定個数、（修正した場合は）「下書き ○個 → 確定 ○個」、メモ、送信状態が表示されます。
- 記録をタップすると、マーカー付き写真を大きく表示でき、日時・個数・数え方・メモ・送信状態の詳細が見られます。
- 記録を左へスワイプすると、その記録を端末から削除できます（サーバーへ送信済みのファイルはサーバー側に残ります）。
